# Personal Portfolio — Greek & English

## How to open the project

1. Extract the ZIP file.
2. Open the extracted folder in Visual Studio Code.
3. Find `index.html` in the Explorer panel.
4. Right-click `index.html` and choose **Open with Live Server**.

## Project files

- `index.html` — the structure and content of the website.
- `style.css` — the colors, layout, spacing and responsive design.
- `script.js` — the language switch and mobile navigation.

## Personal details to update later

In `index.html`, replace:

- `YOUR FULL NAME` with the name you want to display.
- `your.email@example.com` with your professional email address.

The photo placeholder can be replaced with your own image later.

Only list skills and experience that you can confidently explain.
